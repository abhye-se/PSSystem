# Engineering Rules

## Units and conventions

All public engineering quantities must have explicit units or be explicitly per-unit. Sign conventions must be documented and consistent.

## Numerical methods

Numerical tolerances, convergence criteria, iteration limits, and failure modes must be explicit and testable.

## Standards

Where a calculation implements an IEEE, IEC, ANSI, or other standard, documentation must identify the applicable edition and clauses used. Copyrighted standard text must not be copied into the repository.

## Reviews

Changes to equations, model assumptions, numerical tolerances, or benchmark expected values require an explanation in the pull request.
