# Product Vision

PSSystem aims to become a modern, scriptable, transparent power-system analysis environment.

## Product principles

- Engineering correctness before feature count
- Transparent and traceable calculations
- Reproducible studies
- Open programmatic interfaces
- Strong automated validation
- Modern user experience
- Extensible architecture

## Initial analytical scope

The first validated analytical capability is AC steady-state power flow. Short-circuit, protection, dynamics, harmonics, arc-flash, DER, optimal power flow, contingency analysis, and other modules follow only after the common network model is stable.
